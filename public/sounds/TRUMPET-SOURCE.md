# Real trumpet welcome — origin and license

The file `trumpet-welcome.wav` is a short edited montage of **genuine trumpet recordings**, not a synthesized brass oscillator.

## Original recordings

Source: [VSCO 2 Community Edition](https://github.com/sgossner/VSCO-2-CE), commit `440300901dfe9275fd84e0b7763af1f8443ae62e`, directory `Brass/Trumpet/`.

- `stac/Sum_SHTrumpet_stac_F4_v1_rr1.wav`
- `stac/Sum_SHTrumpet_stac_A4_v1_rr1.wav`
- `stac/Sum_SHTrumpet_stac_C5_v1_rr1.wav`

## Editing

The recording combines short original trumpet articulations as a gentle fanfare, trimmed, faded and mixed together. The final `trumpet-welcome.wav` is 24 kHz, mono, 16-bit PCM, roughly 1.25 seconds. It is cached locally by the Malino service worker for offline playback.

The original files are **not** shipped in the app. No remote assets are fetched during playback. The edited file was generated in a one-time GitHub Actions run and committed to the repository.
